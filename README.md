# Portafolio de Favio Solorzano

Laboratorio 14: Next.js, metadatos dinámicos, next/image, sitemap, robots y página de contacto. Diseño Liquid Glass y contenido académico personal.

## Ejecutar

Requiere Node.js 22. Ejecuta npm install, npm run build y npm run start. Para desarrollo, npm run dev.

## Contacto

El formulario valida nombre, correo, asunto y mensaje. Prepara un borrador con un enlace mailto para que el visitante lo revise y envíe desde su propia aplicación de correo. No afirma que un mensaje fue enviado automáticamente ni almacena datos. El envío automático necesitaría un proveedor de correo y sus credenciales.

## Dominio y despliegue

Configura NEXT_PUBLIC_SITE_URL con la URL final, sin barra al final, y reconstruye. Esta variable se utiliza en metadataBase, sitemap, robots y los enlaces canónicos. El despliegue y el dominio se realizarán después de revisar las evidencias locales.

## Verificación

npm run lint y npm run build.
